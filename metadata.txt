about=ST Geometry Provider adds a read-only QGIS data provider for Oracle tables that store geometry in the Esri SDE.ST_GEOMETRY type. Tables become ordinary QGIS layers: rendering, attribute table, identify, selection, filters, expressions, labels and styles work without converting anything to SDO_GEOMETRY and without changing the database. Geometries are decoded locally (numpy batch decoder, verified against Esri's own st_asbinary), fetched in bulk with python-oracledb (fallback: Qt OCI driver), filtered with the ST spatial index or a plain scan chosen per view, optionally merged per pixel for fast overviews, and true curves (arcs) can be read with user-controlled segmentation. Esri, ArcGIS, ArcSDE and ST_Geometry are trademarks of Esri; this plugin is not affiliated with Esri.
